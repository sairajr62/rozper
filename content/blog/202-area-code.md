# 202 Area Code: Washington D.C.'s Complete Business Number Guide

Few prefixes carry as much weight as the 202 area code. It is the original phone code for the nation's capital. It still signals federal, legal, and advocacy credibility. That happens the moment it shows up on a caller ID screen. This guide covers where it reaches. It shows how the 771 overlay changed dialing rules. It also shows how to get a 202 number for your own organization.

---

## What Is the 202 Area Code?

The 202 area code was set up in **1947**. It was one of the first 86 numbering plan codes made under the North American Numbering Plan. Most prefixes cover large counties or whole states. Area code 202 works differently. It was kept only for the **68 square miles** of Washington D.C. That scope is so small it has never needed a single split. This is unlike statewide prefixes such as [the 302 area code](/blog/302-area-code) in neighboring Delaware.

**Quick Facts:**

| Detail | Info |
|---|---|
| Area Code | 202 area code |
| Overlay Code | 771 (launched November 9, 2021) |
| Region | Washington, D.C. |
| Time Zone | Eastern Time (ET) — UTC−5/UTC−4 |
| Dialing | 10-digit mandatory |
| Established | 1947 |
| Regulatory Body | NANPA (North American Numbering Plan Administrator) |

That narrow scope is exactly why the code reads differently than a typical regional prefix. A law firm, a trade group, or a government contractor calling out on a 202 number is clearly rooted in the capital. It is not just rooted in a nearby suburb.

## Where Does the 202 Area Code Cover?

![Map showing the District of Columbia coverage area for the 202 code](/images/blog/202-where-does-the-202-area-code-cover.webp)

Washington D.C. is not part of any state. Because of this, its footprint is small and steady. It covers the whole District. That includes Capitol Hill, Dupont Circle, Georgetown, Foggy Bottom, Navy Yard, and the federal core along the National Mall. It does not spill into Maryland or Virginia. Businesses that grow across the region often pair a 202 number with coverage nearby. A suburban Maryland presence via [the 240 area code](/blog/240-area-code) is a common match. This fits firms that serve both the District and its nearby commuter counties.

The code maps to one dense jurisdiction rather than a spread-out metro area. Because of this, every 202 number reads as clearly D.C.-based. This matters for groups whose credibility depends on being close to federal agencies.

## The 771 Area Code Overlay Explained

![Diagram explaining how the 771 overlay shares the 202 numbering territory](/images/blog/202-the-771-overlay-explained.webp)

By the early 2020s, the District was running low on numbers under 202 alone. A split would have forced half of D.C. to give up its existing prefix. To avoid that, the NANPA brought in **771** as a full overlay on **November 9, 2021**. Both codes now share the same footprint. Every existing 202 number stayed just as it was.

The tradeoff is how you dial. All local calls in the District now need **10-digit dialing**. This is true even when both callers share the same area code 202 exchange. Callers who still dial seven digits out of habit will hear a quick message. It reminds them to add the area code. This is a one-time fix for old phone systems, CRMs, and auto-dialers that store numbers in seven-digit form.

## 202 Area Code Time Zone

![Graphic depicting Eastern Time zone hours observed in Washington D.C.](/images/blog/202-area-code-time-zone.webp)

Washington D.C. sits in the **Eastern Time Zone**. It runs on **EST** (UTC−5) from early November through mid-March. It runs on **EDT** (UTC−4) the rest of the year. So much federal and legislative work follows ET business hours. Because of this, groups calling the District from the West Coast should plan outreach before 2 PM PT. That gives them the best shot at reaching D.C. offices before the end of the business day.

## Is a 202 Area Code Call a Scam?

Like most high-profile prefixes, the 202 area code is a common target for caller-ID spoofing. Scammers pretend to be federal agencies, congressional offices, and advocacy groups. They do this because a 202 number carries built-in trust. Common schemes include fake IRS or Social Security calls that demand quick payment. Others are phony charity asks timed around election cycles. Some are job-offer scams that mention government contracts that don't exist.

Real 202 callers will never demand wire transfers, gift cards, or crypto over the phone. Businesses running a real area code 202 line should use a STIR/SHAKEN-compliant VoIP provider. This way, recipients see a verified caller ID. They will not see a flagged or spoofed-looking number.

## Frequently Asked Questions

**What cities does the 202 area code cover?**
It covers the whole District of Columbia only. It does not reach into Maryland or Virginia suburbs. Those areas use their own area codes.

**What is the difference between 202 and 771?**
Both codes serve the same D.C. footprint. The original D.C. prefix dates to 1947 and has the strongest legacy name recognition. 771 was added as an overlay in November 2021 to stop number exhaustion.

**Is a call from a 202 number a scam?**
Not always. Thousands of real federal offices, law firms, and nonprofits use 202 numbers each day. Still, the prefix gets spoofed often. Never share payment details based on a call you did not expect.

**Can I get a 202 number if my business isn't based in D.C.?**
Yes. Virtual 202 numbers send calls to any device no matter where you are. This is why remote and national groups use them to build a Washington presence.

**Do I need to dial 10 digits for local D.C. calls?**
Yes. Since the 771 overlay began, every local call in the District needs the full 10-digit format. This is true even between two 202 numbers.

**How long does it take to activate a 202 number?**
Most VoIP providers turn on a new 202 number within minutes of purchase. Porting an old number from another carrier can take a few business days instead.
