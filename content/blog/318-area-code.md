## What Is the 318 Area Code?

Area code 318 was established in 1957 when northern Louisiana was split off from the original 504 area code that had served the entire state. The split was one of the earliest in the nation, reflecting the geographic and commercial distinctiveness of northern Louisiana relative to New Orleans and the southern part of the state.

Area code 318 has served the region continuously since then. In 2001, area code 225 was created for the Baton Rouge area, and area code 337 was added for southwestern Louisiana — but 318 retained its coverage of the northern part of the state, including Shreveport, Monroe, and the surrounding region.

**Cities covered by 318:**

- Shreveport
- Bossier City
- Monroe
- West Monroe
- Ruston
- Natchitoches
- Minden
- Bastrop

- Alexandria (shared with 318 and 225 border regions)

**Parishes covered (selection):**
