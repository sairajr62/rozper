## 818 History, Coverage, and Cities

The 818 area code went live on January 7, 1984. It split off from the original 213 code. On June 14, 1997, the eastern San Gabriel Valley got its own code, 626. That change sharpened 818's identity as the code for the San Fernando Valley.

By the 2000s, 818 numbers were running out. Regulators had a choice: split the region again, or add an overlay. They chose the overlay. The new 747 area code took effect on May 18, 2009. Every existing 818 number stayed the same. New numbers simply drew from the 747 pool instead. As with all overlay regions, callers must dial the full area code plus number for every call. This applies even between two 818 lines. The [FCC's ten-digit dialing guide](https://www.fcc.gov/consumers/guides/ten-digit-dialing) confirms this rule.

### Geographic Coverage

The 818 area code covers the San Fernando Valley region of Los Angeles County. Key cities include Burbank, Glendale, San Fernando, Calabasas, and Agoura Hills. It also covers LA neighborhoods such as North Hollywood, Van Nuys, Sherman Oaks, Encino, Tarzana, Woodland Hills, and Northridge. A single 818 number speaks credibly in all of them. That includes a post-production house in Burbank, a family-owned restaurant in Encino, and a startup founder in Woodland Hills.

**What area does the 818 area code cover?**

**What is the 747 area code, and how is it related to 818?**
The 747 area code is an overlay code. It started on May 18, 2009 and covers the exact same area as 818. Regulators added it to create more available numbers. It didn't change anyone's existing line or split the region. New numbers in the area may come with either an 818 or 747 code. Both serve the same San Fernando Valley territory.

**Do I need to dial ten digits for 818 numbers?**
Yes. Because 818 and 747 share the same territory, every call needs ten-digit dialing, even local ones. Always dial the full 818 area code plus the seven-digit number. This applies even when you call a neighbor in the same ZIP code.

**What time zone is the 818 area code in?**
The 818 area code sits entirely in the Pacific Time Zone. That's PST (UTC-8) in standard time and PDT (UTC-7) during daylight saving. If your business schedules calls to this region, plan around Pacific business hours. That way, you reach contacts during their working day.
