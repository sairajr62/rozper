## 818 History, Coverage, and Cities

The 818 area code entered service on January 7, 1984, split from the original 213. On June 14, 1997, the eastern San Gabriel Valley was spun off into the new 626 area code, sharpening 818's identity around the San Fernando Valley.

By the 2000s, available 818 numbers were thinning out. Rather than split the region again, regulators approved an overlay: the 747 area code, which took effect on May 18, 2009. Every existing 818 subscriber kept their number untouched while fresh numbers became available. As with all overlay regions, the [FCC's ten-digit dialing guide](https://www.fcc.gov/consumers/guides/ten-digit-dialing) confirms that callers must dial the full area code plus number for every call, even between two 818 lines.

### Geographic Coverage

Key cities include Burbank, Glendale, San Fernando, Calabasas, and Agoura Hills, plus LA neighborhoods such as North Hollywood, Van Nuys, Sherman Oaks, Encino, Tarzana, Woodland Hills, and Northridge. ## Frequently Asked Questions

**What area does the 818 area code cover?**
The 818 area code covers the San Fernando Valley region of Los Angeles County, California. That includes cities like Burbank, Glendale, San Fernando, Calabasas, Hidden Hills, and Agoura Hills, plus LA neighborhoods such as North Hollywood, Van Nuys, Sherman Oaks, Encino, Tarzana, Woodland Hills, and Northridge.

**What is the 747 area code, and how is it related to 818?**
The 747 area code is an overlay code introduced on May 18, 2009 that shares the exact same geographic area as 818. It was added to create more available numbers without changing anyone's existing line or splitting the region geographically. New numbers in the region may be issued with either an 818 or 747 code — both serve the same San Fernando Valley territory.

**Do I need to dial ten digits for 818 numbers?**
Yes. Because 818 and 747 overlay the same territory, ten-digit dialing is required for all calls — including local ones. Always dial the full 818 area code followed by the seven-digit number, even when calling a neighbor in the same ZIP code.

**What time zone is the 818 area code in?**
The 818 area code is entirely in the Pacific Time Zone — PST (UTC-8) in standard time and PDT (UTC-7) during daylight saving. Any business scheduling calls to the region should plan around Pacific business hours to reach contacts during their working day.

**Can I get an 818 number if my business is outside Los Angeles?**
