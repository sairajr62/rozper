## What Is the 669 Area Code? History, Coverage, and Cities

The story of area code 669 begins not in 2012, but in 1959 — when area code 408 was created by splitting off from the original area code 415 that had served all of Northern California since the North American Numbering Plan launched in 1947. For nearly four decades, 408 served the entire greater San Jose region without relief. Then came the internet.

The explosion of pagers, fax machines, dial-up modems, and eventually mobile phones drove rapid number exhaustion across Northern California. In 1998, the southern portion of 408's territory was reassigned to a new area code, 831, covering the Monterey Bay area, Santa Cruz, and the Salinas Valley. The reduction bought time — but not enough.

By 2011, the California Public Utilities Commission projected that the remaining 408 number pool would be fully exhausted by mid-2012. Rather than another geographic split, the CPUC chose a different approach: on October 20, 2011, it approved area code 669 as a full overlay of the 408 numbering plan area. An overlay means the new code covers the same geography as the existing one — the region doesn't split, and no one is forced to change their existing 408 number.

New telephone lines and services began receiving 669 numbers on November 20, 2012. Because 408 and 669 share the same geographic footprint, ten-digit dialing — area code plus number — has been required for all local calls throughout the 408/669 overlay since the new code launched.

## Frequently Asked Questions

**What cities does the 669 area code cover?**
Area code 669 is an overlay of area code 408, covering the same geographic footprint: the majority of Santa Clara County plus portions of Alameda and northern Santa Cruz County. Key cities include San Jose, Sunnyvale, Santa Clara, Cupertino, Mountain View, Milpitas, Campbell, Los Gatos, Saratoga, Morgan Hill, and Gilroy — the core of Silicon Valley and the South Bay region.

**Why does Silicon Valley have two area codes — 408 and 669?**
Area code 408 was established in 1959 and served the entire region for decades. By 2011, explosive demand from mobile phones, VoIP services, IoT devices, and business lines exhausted the available 408 number supply. Rather than split the region geographically, the California Public Utilities Commission approved 669 as a full overlay in 2011, with new numbers in 669 available starting November 2012. Both codes serve the same geography; callers simply need to dial all ten digits regardless of which code is used.

**Is ten-digit dialing required for 669 area code calls?**
Yes. Because 408 and 669 are an overlay pair sharing the same geographic area, ten-digit dialing — the full area code plus the seven-digit number — has been required for all local calls within the region since 669 launched in 2012. This applies to calls between two 408 numbers, two 669 numbers, and calls between the two codes.

**Can a business outside California use a 669 area code number?**

**Does California have special rules for recording calls on a 669 number?**
Yes. California operates under a two-party (or "all-party") consent standard. Under California Penal Code § 632, all parties to a call must consent before the call may be recorded. Businesses using their 669 number to record calls must provide audible disclosure — typically an automated announcement at the start of the call — before recording begins. Most professional VoIP platforms include automated consent prompts that handle this requirement.
