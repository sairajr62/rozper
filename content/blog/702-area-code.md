## A Brief History of the Prefix

The 702 area code dates back to October 1947. It was one of the first numbering plan areas made for the whole state of Nevada. For more than fifty years, this one code covered every city in the state, from Reno to Henderson. That changed on December 12, 1998. Planners split the state to fix a coming shortage. Everything outside Clark County, including Reno and Carson City, moved to the newer 775 code. That left Las Vegas tied only to its first code.

Even after the split, growth in Southern Nevada stayed fast. By 2014, planners brought in 725 as an overlay rather than splitting the region again. Old customers kept their same numbers, while new lines could use either code. This overlay is why any phone number in the valley today needs ten-digit dialing to complete a call. It does not matter if the number starts with the old code or the new one.

## Time Zone and Dialing Format

Every town inside the 702 area code runs on Pacific Time. It uses Pacific Standard Time in winter and Pacific Daylight Time in summer. That places Las Vegas one to three hours behind most of the country. Callers should note this when planning business calls across state lines.

Area code 702 shares its land with the 725 overlay. So the ten-digit dialing rule applies to every local call, even between two neighbors on the same street. For a deeper look at how the overlay was set up, the [Wikipedia entry on area codes 702 and 725](https://en.wikipedia.org/wiki/Area_codes_702_and_725) offers a clear timeline of the changes. Getting used to ten-digit dialing is a small change. But it stays key for anyone calling into or out of the valley today.
