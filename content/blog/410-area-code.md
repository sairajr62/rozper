## What Is the 410 Area Code?

Area code 410 was created in November 1991 when it split from area code 301 that had previously served all of Maryland. As the Baltimore metro grew and the demand for new numbers increased, 301 was divided: the western and southern portions of Maryland (including the DC suburbs in Montgomery and Prince George's counties) retained 301, while the Baltimore metro area and the Eastern Shore were assigned the new 410 area code.

As the Baltimore area continued to grow, area code 443 was added as an overlay in 1997, and area code 667 was added as a second overlay in 2012. Because multiple codes share the same geography, ten-digit dialing is required for all local calls.
