## What Is the 919 Area Code and Where Does It Apply?

The 919 area code serves the Research Triangle region of North Carolina — anchored by Raleigh, Durham, and Chapel Hill. It was established in **1954** as a split from area code 704, which at the time covered the entire state.

In 1993, the western and southern portions split off into area code 910. In 1998, the northeastern portion formed area code 252. Both splits sharpened 919's footprint around the Triangle metro.

Area code **984 was introduced as an overlay** in 2012. Mandatory ten-digit dialing took effect on **April 1, 2012**. Both 919 and 984 now serve the same territory, and all local calls require a full 10-digit number.

The 919 area code operates in the **Eastern Time Zone**.
