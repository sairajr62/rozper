## What Is the 314 Area Code?

Area code 314 is one of the original area codes from 1947, assigned to Missouri when the North American Numbering Plan first launched. For decades, it covered a large portion of the state. As the St. Louis metro grew, the code was progressively refined: area code 573 was split off to serve outstate Missouri in 1996, and area code 636 was created in 1999 to serve the rapidly growing western and southwestern suburbs of St. Louis.

Today, 314 serves the core St. Louis metro — the city of St. Louis and the inner-ring suburbs of St. Louis County. Area code 557 was added as an overlay for the same territory in 2011.
