## What Is the 979 Area Code?

![Map highlighting the Brazos River corridor and southeastern Texas cities served by the 979 prefix](/images/blog/what-is-979-area-code.webp)

The **979 area code** is a North American Numbering Plan (NANP) code for southeastern Texas. It runs along the Brazos River corridor. Coverage stretches from just south of Waco down to the Gulf Coast.

The **979 area code** started on February 13, 2000. It came from a split of the older 409 code. That code had covered the region since 1947. Texas regulators planned the split with federal number officials. More people, more cell phones, and more business use had used up most 409 numbers. A three-way split fixed the shortage.

Every caller in **area code 979** sits in the Central Time Zone. That means UTC−6 in standard time. It means UTC−5 in Daylight Saving Time. The 979 code has no overlay. It is the only code for its area. That means all calls use 10 digits, even local ones.

## A Brief History of the 979 Area Code

![Timeline illustration of the 409 area code split that created the 979 area code in 2000](/images/blog/inner 3.png)

The story starts with the original 409 code. It served all of southeastern Texas starting in 1947. By the late 1990s, mobile phones, fax machines, and dial-up internet had eaten up most available numbers.

Regulators needed a fix. An overlay code would have forced everyone to dial 10 digits, no matter where they called. The PUCT chose a different path instead. They approved a three-way split of 409. That kept seven-digit dialing for existing customers and eased the transition.

The **979 area code** went live on February 13, 2000. It took over the northern and western parts of the old 409 territory. The southern coast kept the 409 name. A separate split later gave relief to the Beaumont and Port Arthur area too.

Since then, the **979 area code** has become the local identity for the Brazos River corridor. Businesses and residents across the region now associate it with home.
