## What Is the 931 Area Code?

![Map highlighting the horseshoe-shaped 931 area code territory around Nashville](/images/blog/what-is-the-931-area-code.webp)

The **931 area code** is a phone code set by the NANP system. It serves central and south Tennessee. It covers 28 counties. The shape is like a horseshoe around Nashville. It runs from the Kentucky line down through the Highland Rim. It reaches the Cumberland Plateau too.

The code began on September 15, 1997. It split off from the old 615 area code. Back then, 615 covered nearly all of Middle Tennessee. Then growth used up the numbers. More people moved in. Fax machines spread fast. Early internet use grew too.

The **931 area code** sits in the Central Time Zone. That means UTC−6 in standard time. It shifts to UTC−5 in Daylight Saving Time. Every call in **area code 931** uses the standard 10-digit format.

## A Brief History of the 931 Area Code

![Timeline illustration of the 1997 split from the 615 area code that created the 931 area code](/images/blog/history-931-area-code.webp)

The **931 area code** owes its start to fast growth in the 1980s and 1990s. For years, the 615 code covered nearly the whole state. Then things changed. More people moved in. Fax machines showed up in every office. Early internet use grew too. Soon, 615 ran low on numbers.

Regulators had one clear fix. Split the region. The **931 area code** launched on September 15, 1997. It took the outer horseshoe of Middle Tennessee out of 615's old zone. A grace period came next. People could still dial 615 until January 15, 1998. This gave everyone time to switch over with ease.

The split let Nashville keep its old 615 code. The wider region, from central to south Tennessee, took on 931. Today, that number marks towns from Clarksville all the way to the Cumberland Plateau.
