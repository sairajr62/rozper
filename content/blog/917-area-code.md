## What Is the 917 Area Code and Where Does It Apply?

The 917 area code is a citywide overlay for New York City, covering all five boroughs — Manhattan, Brooklyn, Queens, The Bronx, and Staten Island — alongside the other NYC overlay codes (212, 332, 646, 718, 347, and 929).

**Time zone:** Eastern Time (ET) — UTC−5 (November to March) and UTC−4 during Daylight Saving Time.

**Area code history:**
- 1947 — Original 212 code assigned to all of New York State
- 1984 — 718 split to serve the outer boroughs
- 1992 — 917 introduced as the first NANP overlay code (cellular/pager only)
- 1999 — 646 and 347 added as Manhattan and outer borough overlays
- 2011 — 929 added for outer boroughs; 917 extended to landlines
- 2026 — Area code 465 approved by the New York PSC, in-service June 18, 2026

Existing NYC codes are projected to exhaust in Q4 2026. If establishing a 917 number is on your roadmap, now is the time.
