## 805 History, Coverage, and Cities

The 805 area code began in 1957. It split off from area code 213. In 1999, the CPUC created area code 661 for the San Joaquin Valley. That change kept 805 focused on the coast. By 2017, the CPUC approved area code 820 as a full overlay for the same region. New 820 numbers started in June 2018. This locked in ten-digit dialing for the area. But every existing 805 number stayed the same. No one had to change their number.

### Geographic Coverage

The 805 area code covers most of Ventura, Santa Barbara, and San Luis Obispo counties. It also reaches small parts of Kern, Monterey, and northern Los Angeles County. Key cities include Ventura and Oxnard. They also include Thousand Oaks, Santa Barbara, and Santa Maria. San Luis Obispo and Paso Robles round out the list. That range means one 805 number can speak to clients across many kinds of local business.

## Frequently Asked Questions

It also reaches small parts of Kern, Monterey, and northern Los Angeles counties. Major cities include Ventura, Oxnard, and Thousand Oaks. **What time zone does the 805 area code use?**
The 805 area code sits entirely in the Pacific Time Zone. That is PST (UTC-8) in standard time and PDT (UTC-7) during daylight saving. Always plan around Pacific hours when you schedule calls or outbound campaigns for the Central Coast.

**Do I have to dial ten digits for 805 numbers?**
Yes. The 805 region shares its territory with the 820 overlay code from 2018. Because of that, ten-digit dialing is required for all calls, even local ones. Always dial the full 805 area code plus the seven-digit number, even when calling within the same region.

**Is the 805 area code the same as 820?**
Not exactly. Area code 820 is an overlay added in June 2018. It covers the same territory as 805 and was created to add more available numbers. New lines may carry an 820 code. But every established 805 number stayed the same and still works normally.
