## What Is the 805 Area Code? History, Coverage, and Cities

The story of area code 805 begins in 1957 — when it was created by splitting off from area code 213, which had blanketed all of Southern California since the North American Numbering Plan was established in 1947. At the time, 805 covered an enormous stretch of California real estate, from the Central Coast down through the San Joaquin Valley and beyond.

As California's population and its appetite for telephone lines grew, the 805 territory was progressively refined. In 1999, the California Public Utilities Commission carved out area code 661, reassigning the San Joaquin Valley, Santa Clarita, and the Antelope Valley to the new code. That reduction sharpened 805's identity, concentrating it along the coast and giving it the distinctive regional character it carries today.

By the mid-2010s, even the trimmed-down 805 pool was running low. Rather than split the region geographically — which would have forced existing holders to change their numbers — the CPUC approved area code 820 as a full overlay of the 805 numbering plan area in 2017. New 820 numbers began entering service in June 2018. Every existing 805 subscriber kept their number untouched; the overlay simply added a second code across the same geography and locked in ten-digit dialing for everyone in the region.

The practical result for businesses today: an established 805 number is a slightly scarcer, and therefore more distinctive, regional asset — one that carries the implicit credibility of longevity along one of California's most recognizable coastlines.

**What time zone does the 805 area code use?**
The 805 area code is entirely in the Pacific Time Zone — PST (UTC-8) in standard time and PDT (UTC-7) during daylight saving. Schedule any calls to the region around Pacific hours.

**Do I have to dial ten digits for 805 numbers?**
Yes. Because the 805 region shares its territory with the 820 overlay code introduced in 2018, ten-digit dialing is required for all calls — including local ones. Always dial the full 805 area code followed by the seven-digit number.

Not exactly. 820 is an overlay code introduced in June 2018 that covers the same geographic area as 805, created to expand the available number supply. Existing 805 numbers were unaffected by the overlay — new lines may be assigned an 820 code, but all established 805 numbers remained unchanged.
