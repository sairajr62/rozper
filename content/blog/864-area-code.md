## 864 History, Coverage, and Cities

For 48 years, 803 was the only area code in all of South Carolina. As numbers ran short and the Upstate's population and business base expanded, the region was split off into the new 864 area code on December 3, 1995. By the 2020s, the available 864 number pool was again running low, prompting the addition of the 821 overlay on August 19, 2024 — which covers the same geography and adds a new pool of numbers while making ten-digit dialing mandatory across the region.

An established 864 number is a touch more distinctive today, since brand-new lines may carry the 821 code instead. Major hubs in the 864 footprint include Greenville, Spartanburg, and Anderson, along with surrounding communities like Greer, Mauldin, Clemson, and Gaffney.

## Frequently Asked Questions

**Where is the 864 area code located?**
The 864 area code covers the Upstate region — the western third of South Carolina. It includes Greenville, Spartanburg, and Anderson, plus roughly a dozen surrounding counties and cities such as Greer, Mauldin, Clemson, and Gaffney, stretching from the Blue Ridge foothills toward the state's midlands.

**What is the 821 area code, and how is it related to 864?**
821 is an overlay code added on August 19, 2024 that covers the exact same geographic area as 864. It was introduced to create more available numbers without changing anyone's existing line or splitting the region geographically, so new numbers in the Upstate may now carry either an 864 or 821 code — both serve the same territory.

**Do I have to dial ten digits for 864 numbers?**
Yes. Because 864 and 821 overlay the same territory, ten-digit dialing is required for all calls — including local ones. Always dial the full 864 area code followed by the seven-digit number, even when calling a neighbor or a business down the street.

**What time zone is the 864 area code in?**
The 864 area code is in the Eastern Time Zone — EST (UTC-5) in standard time and EDT (UTC-4) during daylight saving time. When scheduling calls to the region, plan around standard Eastern business hours to reach contacts during their working day.

**Can I get an 864 number if my business isn't in South Carolina?**
Yes. With a virtual number provider, you can claim area code 864 from anywhere and route calls to your existing devices. It is a common, affordable strategy for building a trusted local presence in the Upstate without requiring a physical office or local staff in the region.
