## What Is the 864 Area Code? History, Coverage, and Cities

The story of area code 864 begins with a rarity: for 48 years, 803 was the only area code in all of South Carolina. As numbers ran short across the state and the Upstate's population and business base expanded, the region was split off into the new 864 area code on December 3, 1995 — giving northwestern South Carolina its own distinct identity on the phone.

The region kept growing. By the 2020s, the available 864 number pool was again running low. Rather than split the territory a second time — which would have forced existing holders to change their numbers — regulators added an overlay: the 821 area code, which took effect on August 19, 2024. Because 821 overlays the same geography, it shares 864's boundaries and simply adds a new pool of numbers, while making ten-digit dialing the rule for everyone in the region.

The practical result for businesses today: an established 864 number is a touch more distinctive, since brand-new lines may carry the 821 code instead — making an existing 864 number a quiet signal of regional longevity.

821 is an overlay code added on August 19, 2024 that covers the exact same geographic area as 864.
