## What Is the 385 Area Code?

Area code 385 was established in 2012 as an overlay for Utah. The original area code for Utah is 801, which has served the state since 1947. As Utah's population grew — particularly along the Wasatch Front, which experienced some of the fastest urban growth in the country during the 2000s and 2010s — the demand for new phone numbers outpaced what 801 alone could supply.

Rather than splitting the geographic territory, 385 was added as an overlay for the entire state of Utah, meaning both 385 and 801 serve the same geography. Ten-digit dialing is required for all local calls within the overlay area.
