## What Is the 252 Area Code?

Area code 252 was created on February 1, 1998, when it split from the 919 area code that had served most of North Carolina. As the state's population grew and telecommunications demand expanded, 919 was divided: the Triangle area (Raleigh, Durham, Chapel Hill) retained 919, while Eastern North Carolina was assigned the new 252 code.

The 252 area code serves a large geographic territory covering much of the coastal plain and the Outer Banks, making it the defining local identifier for businesses operating across Eastern NC.
