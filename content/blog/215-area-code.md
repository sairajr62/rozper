## What Is the 215 Area Code?

Area code 215 is one of the original telephone codes established when the North American Numbering Plan launched in 1947. At that time, it served all of southeastern Pennsylvania — a vast territory. As the region's population expanded through the latter half of the 20th century, demand for phone numbers outpaced what a single code could supply.

### The Genesis and Evolution

The first major change came in 1994, when area code 610 was split off to serve the western and southern Philadelphia suburbs — Delaware, Chester, and Montgomery counties. In 1998, 267 was introduced as a second overlay code serving the same territory as 215 — the Philadelphia city proper and Bucks County. Because 215 and 267 cover the same geography, all local calls require 10-digit dialing. **What cities does the 215 area code cover?**

**When was the 215 area code created?**
Area code 215 was one of the original NANP codes established in 1947, originally serving all of southeastern Pennsylvania.
