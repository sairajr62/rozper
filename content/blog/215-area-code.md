## What Is the 215 Area Code?

Area code 215 is one of the original area codes assigned when the North American Numbering Plan launched in 1947. It has served Philadelphia and its surrounding counties since the beginning, making it one of the most historically established local identifiers in the country.

As the region grew, the demand for new numbers increased. Area code 267 was added as an overlay for the same geographic territory in 1994, and area code 445 was added as a second overlay in 2010. Because multiple codes share the same geography, ten-digit dialing is required for all local calls within the 215/267/445 area.

- Bristol

**Counties covered:**
