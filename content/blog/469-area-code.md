## The History Behind Area Code 469

When the North American Numbering Plan launched in 1947, area code 214 handled all of North and East Texas. As Dallas expanded, demand for new numbers outpaced what a single code could supply.

- **1947:** Area code 214 assigned, covering North and East Texas.
- **1995:** Area code 903 splits off for East Texas.
- **1996:** Area code 972 carved out of 214, covering Dallas suburbs — Plano, McKinney, Frisco, Irving, and Collin and Denton counties.
- **1999:** The 214/972 boundary dissolves. Area code 469 launches as a full overlay with mandatory 10-digit dialing.
- **2021:** Area code 945 added as a fourth overlay.

Today, 214, 469, 972, and 945 all serve the same geographic territory — including AT&T's corporate headquarters.

## The 214/469/972/945 Overlay: What It Means for Callers

Four area codes cover the exact same geographic territory. New numbers are assigned from whichever code has availability, but existing customers keep their original code permanently.

**Key dialing rules:**

- All local calls require **10-digit dialing** — area code plus 7-digit number
- Dialing only 7 digits results in a failed call
- Calls to 911, 988, and N11 service codes remain standard 3-digit

Dialing 1 plus the area code does **not** make a call long-distance — local rates apply throughout the 214/469/972/945 region. The FCC mandated 10-digit dialing for routing accuracy, not billing.

Area code 945 was added in 2021 when number demand was depleting available supply. Rather than force a geographic split, regulators approved it as a fourth overlay with no transition period needed.
