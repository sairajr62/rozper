# 562 Area Code: Long Beach, CA — Cities, Location & Business Guide

The Port of Long Beach moved 9.9 million twenty-foot equivalent units of cargo in one year. That makes it the second-busiest container port in the United States. The 562 area code is the phone identity of southeastern LA County.

## What Is the 562 Area Code?

The **562 area code** is a California phone code from NANPA. It covers the southeast part of Los Angeles County and a small part of the northwest corner of Orange County. It was created on April 4, 1997. The 310 area code had run out of numbers because mobile phone use grew so fast. Long Beach is the anchor city. It has about 470,000 residents.

## The 1997 Split: Why the 562 Area Code Exists

![Long Beach Telephone Code History Timeline — 1997 Split and Key Milestones](/images/blog/562-image-4.webp)

The 310 area code split from 213 in 1991. This handled the western and southern parts of LA County. By the mid-1990s, fast mobile phone growth had used up all 310 numbers. This forced another split. On April 4, 1997, area code 562 was carved from 310. This gave the southeast corridor its own phone identity. Businesses serving downtown Los Angeles may also want to know about the [323 area code](/blog/323-area-code). It can help build a broader local presence across the metro.

## Time Zone and Dialing Rules

![10-Digit Dialing and Pacific Time Zone Guide for the 562](/images/blog/562-image-3.webp)

This region sits entirely within the **Pacific Time Zone (PT)**. It uses PST (UTC−8) from early November to mid-March. It switches to PDT (UTC−7) from mid-March to early November.

### 10-Digit Dialing Is Mandatory

As of **October 24, 2021**, all calls in the region need 10-digit dialing. This change came ahead of the nationwide 988 mental health crisis line rollout. Businesses with older PBX systems should check their internal setup for compliance.

## Is the 562 Area Code Associated With Scams?

The **562 area code** is entirely legitimate. It serves about 1.5 million residents and thousands of businesses. But scammers spoof these numbers. The Long Beach name makes calls seem real to local people.

Common scams use fake process server calls, fake IRS calls, and robo-calls about real estate, all from spoofed local numbers. Real government agencies never ask for instant payment on a cold call. If you get a call that feels off, hang up. Look up the agency and call that number instead. Do not use any callback number the caller gives you.
