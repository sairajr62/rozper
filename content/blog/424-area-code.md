## What Is the 424 Area Code?

Area code 424 was established in 2006 as an overlay for area code 310. Area code 310 had been serving the western and southwestern portions of Los Angeles County since 1984, when it was split from the original 213 area code. As the density of businesses and residents in the South Bay and Westside continued to grow, 424 was added as an overlay to handle the demand for new numbers in the same geographic territory.

Because 424 and 310 are overlays of the same area, ten-digit dialing is required for all local calls within the region.
