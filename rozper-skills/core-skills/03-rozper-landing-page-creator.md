# Rozper Landing Page Creator

Create high-converting, SEO-optimized, sales-focused landing pages for Rozper. SHORT, SCANNABLE, SALES-DRIVEN.

**Core philosophy:** Landing pages sell in seconds. Every element moves the visitor toward one CTA.
**This skill handles the HOW.** Pair with `rozper-company-info` for the WHAT.

---

## THE #1 RULE: NOT A BLOG

| Blog Post | Landing Page |
|-----------|-------------|
| Long H1 (12-20 words) | Short H1 (6-10 words) |
| Story opener paragraphs | Subheadline + CTA button |
| Flowing paragraphs | Bullet points + stat callouts |
| Educational tone | Sales tone — direct, confident |
| 1,000-2,000 words | 400-700 words |
| Multiple CTA types | One CTA repeated 2-3x |

---

## CONTENT UNIQUENESS — ZERO-REUSE RULE (MANDATORY)

1. NEVER reuse H1 structure — not even pattern swaps
2. NEVER reuse subheadline patterns
3. NEVER reuse body section structures or topic order
4. NEVER reuse CTA button text
5. NEVER reuse FAQ questions (even rephrased)
6. EVERY page must feel written from scratch

**Before writing, declare:**
```
Previously Used H1s: [list]
This Page H1: [completely different]
Previously Used Angles: [list]
This Page Angle: [completely different]
```

## PAGE STRUCTURE (6-7 SECTIONS)

### Section 1: Hero
```
H1: [6-10 words — outcome or bold claim]
Subheadline: [who it's for + what they get — 1 line]
CTA: [ Start a No-Pressure Conversation → rozper.com ]
Trust line: "99.999% Uptime  |  150+ Countries  |  24/7 Expert Support  |  Risk-Free Trial"
```

**H1 patterns that work for Rozper:**
- Outcome: "[Specific result] Without [Pain Point]"
- Direct: "[Primary Product] Built for [Target Audience]"
- Number-led: "[Coverage/stat]. [Benefit]. [Differentiator]."
- Contrast: "Enterprise [Feature]. [Simplicity angle]."

### Section 2: Problem (2-3 sentences)
Name the pain. Be specific. No fluff.

### Section 3: Solution — Rozper Features
3-5 bullet points: **[Feature]** — [specific business benefit]

Highlight at minimum:
- 99.999% uptime SLA → what it means for the buyer
- 150+ countries → what reach means in practice
- Partnership model — genuine human support, 99.999% uptime, 150+ countries

### Section 4: Social Proof / Trust Stats
2-3 proof points. Specific beats vague.

### Section 5: Feature Icons (Scannable)
4-6 icon + headline combos. No paragraphs.

### Section 6: FAQ (4-5 Questions)
Answer directly in 2-3 sentences. Include FAQ schema.

### Section 7: Final CTA
```
[Benefit statement for this page]
[ Start a No-Pressure Conversation → rozper.com ]
UCaaS, Wholesale Voice, Virtual Numbers, SIP Trunking, Bulk SMS
99.999% Uptime  |  150+ Countries  |  24/7 Expert Support  |  Risk-Free Trial
```

## SEO RULES

**Meta title:** `[Primary Keyword] — [Differentiator] | Rozper`
**Meta description:** `[Keyword] for [audience]. [Key differentiator]. [Start a No-Pressure Conversation]. rozper.com`

**Keyword density:**
- Primary keyword: 4-6 mentions max
- Secondary: 2-3 mentions each
- No stuffing — if robotic, rewrite

---

## HUMANIZATION RULES

1. Start sentences with "You", "Your", "Here's" — not "In today's world"
2. Use contractions: "you're", "it's", "we've"
3. Vary sentence length: mix 4-word punches with 15-word explanations
4. One conversational aside per page
5. Avoid all banned phrases from `../reference-files/03-rozper-banned-words.md`
