# Rozper Blog Creator

Create high-quality, SEO-optimized blog posts for Rozper. Educational, informational content — not sales pages.

**This skill handles the HOW.** Pair with `rozper-company-info` for brand facts.

---

## ZERO-REUSE RULE (MANDATORY)

1. NEVER reuse title/H1 structure
2. NEVER reuse intro hooks or patterns
3. NEVER reuse body section structures or topic order
4. NEVER reuse CTA copy
5. NEVER reuse FAQ questions (even rephrased)
6. NEVER reuse conclusion approach

**Before writing, check and declare what will be DIFFERENT from all previous Rozper posts.**

---

## BLOG FORMAT TYPES

### Type 1: How-To Guide
Keywords: "how to [action]"
Structure: Why it matters → What you need → Step-by-step → Mistakes to avoid → Summary → Rozper CTA

### Type 2: Listicle
Keywords: "best X", "top X tools", "X reasons"
Structure: Intro → Numbered items (5-12) with subheadlines → Summary table → Bottom CTA

### Type 3: Comparison Post
Keywords: "[A] vs [B]", "alternatives to X"
Structure: Quick verdict → Comparison table → Deep dive per option → Rozper as alternative → FAQ

### Type 4: Ultimate Guide
Keywords: "complete guide to X", "everything about X"
Target: 2,500-4,000 words
Structure: TOC → Definition → 4-7 H2 sections → Subsections → FAQ → CTA

### Type 5: Case Study
Keywords: "how [company] achieved [result]"
Structure: Challenge → Solution → Results with metrics → Takeaways → CTA

### Type 6: News/Trend
Keywords: "X trends for [year]", "latest in X"
Structure: News hook → Why it matters → 3-5 trend breakdowns → What to do → Rozper angle → CTA

### Type 7: Pillar Page
Target: 3,000-4,000 words
Structure: Comprehensive overview → All sub-topics at intro depth → Internal links → FAQ

## PRE-WRITING RESEARCH (NEVER SKIP)

1. Search keyword → top 5 organic results
2. For each: note H1 angle, word count, sections covered, what's MISSING
3. Check People Also Ask → 5-8 questions → use 3-4 in FAQ, 1-2 as H2s
4. Confirm search intent (informational vs commercial vs navigational)
5. Find the unique angle: what are all competitors NOT covering?

**Rozper-specific content gaps to exploit:**
- Human-first partnership, 99.999% uptime, 150+ countries, custom pricing not mentioned by competitors
- 99.999% uptime specifics never shown
- 150+ countries coverage angle
- Partnership model — genuine human support, 99.999% uptime, 150+ countries

## WRITING RULES

### Opening Hook Options (rotate — never repeat):
1. Stat hook: "[Specific industry stat] — here's what that means for [audience]"
2. Question hook: "[Challenging question that the reader is asking]"
3. Bold claim: "[Counterintuitive statement about the topic]"
4. Scenario: "Imagine [specific situation your reader faces]"
5. Direct challenge: "If you're still [old approach], this changes everything"

### Rozper Integration in Blog Posts:
- Mention no earlier than 40% into the post
- Frame as "one option worth considering" — not forced sales
- 1-2 natural mentions per 1,500 words
- End with soft CTA: "See how Rozper handles this at rozper.com"

### Data Rules:
- At least 2 specific stats per post
- Never fabricate — use real industry data or Rozper stats
- Key Rozper stats: 99.999% uptime, 150+ countries, Human-first partnership, 99.999% uptime, 150+ countries, custom pricing

---

## SEO RULES

**Meta title:** `[Primary Keyword]: [Hook] ([Year if relevant])`
**Meta description:** `[Problem] + [what post solves] + [hint at answer]. Max 155 chars.`

**Keyword density (per 1,500 words):**
- Primary keyword: 6-8 mentions
- Secondary: 2-4 each
- Internal links: 2-3 to Rozper product pages
