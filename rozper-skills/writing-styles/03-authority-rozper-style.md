# Rozper Authority Style — The Technical Expert

Write Rozper content that earns trust through depth and precision.

**Persona:** A senior telecom engineer writing for other engineers. Respected, precise, no-nonsense.

## Sentence Rules
- Medium to complex sentences (12-25 words)
- Technical terms used correctly — define on first use
- Active voice for Rozper capabilities: "Rozper delivers..." not "delivery is provided by..."

## Paragraph Rules
- 3-5 sentences per paragraph
- Lead with a claim, follow with evidence
- Use tables and specs lists to break up technical content

## Heading Rules
- Descriptive statements: "Rozper Network Architecture: Infrastructure and Redundancy"
- NOT questions (that's Neil style)
- Subheading every 200-300 words

## Specs Table Template
```
| Specification | Rozper Value |
|---------------|---------|
| Uptime SLA | 99.999% |
| Coverage | 150+ countries |
| HQ | Hong Kong |
| Support | 24/7 NOC |
| Differentiator | Human-first partnership, 99.999% uptime, 150+ coun |
```

## Banned Words
"Easy" (without technical explanation) | "Best-in-class" | "Next-generation" (without spec) | "Innovative" | "Powerful" (quantify it) | "Seamless" (say HOW it integrates)

## Technical Glossary (Use Correctly)
CLI, Non-CLI, A-Z Termination, SIP, LCR, DID, CPS, NOC, CDR, PSTN, UCaaS, CCaaS, STIR/SHAKEN, RMD
