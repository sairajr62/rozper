# Rozper Banned Words & Phrases

These phrases make content sound AI-generated, generic, or untrustworthy. All are BANNED from Rozper content.

---

## CRITICAL BANS — Never Use (Instant Rewrite)

| Banned Phrase | Use Instead |
|---------------|-------------|
| "In today's digital landscape" | Start with a specific claim or problem |
| "In today's fast-paced world" | Start with a stat or scenario |
| "As we navigate [anything]" | Be direct about what's happening |
| "It is worth noting that" | Say it directly |
| "It goes without saying" | Delete and say what matters |
| "That being said" | Delete or use "But" / "However" |
| "With that in mind" | Delete |
| "At the end of the day" | Say the actual conclusion |
| "In conclusion" | Just conclude without announcing it |
| "In this article, we will discuss" | Just start |
| "Game-changer" | Show the specific change |
| "Revolutionize" | Show what specifically changes |
| "Next-generation" | Specify what generation means technically |
| "World-class" | Give the spec that proves it |
| "Best-in-class" | Give the ranking or stat |
| "Industry-leading" | Give the number |
| "State-of-the-art" | Name the actual technology |

## TELECOM-SPECIFIC BANS

| Banned Phrase | Use Instead |
|---------------|-------------|
| "Seamless integration" | "[Tool] connects with your [system] in [X] minutes" |
| "Robust infrastructure" | "Carrier-grade network with 99.999% uptime SLA" |
| "Robust solution" | Name the actual capability |
| "Cutting-edge technology" | Name the technology |
| "Innovative solution" | Say what's innovative |
| "End-to-end solution" | List what it actually covers |
| "Mission-critical" | "You can't afford downtime" |
| "Future-proof" | Explain what future scenarios it handles |
| "Value-added" | List what the value actually is |
| "Turnkey solution" | "Set up in minutes, fully operational" |
| "Out-of-the-box" | "Works immediately without custom configuration" |

---

## WEAK VERBS TO AVOID

| Weak | Replace With |
|------|-------------|
| "Utilize" | "Use" |
| "Leverage" (as tech verb) | "Use", "Apply", describe the action |
| "Facilitate" | "Enable", "Allow", "Help" |
| "Endeavor" | "Try", "Work to" |
| "Obtain" | "Get" |
| "Very" (intensifier) | Delete or find specific word |
| "Really" (intensifier) | Delete |
| "Various" | List them |
| "Several" | How many exactly |
| "Numerous" | Give the number |

---

## VAGUE BENEFIT PHRASES (Show, Don't Tell)

| Vague | Replace With |
|-------|-------------|
| "Improves productivity" | "[X hours] saved per [period]" or specific % |
| "Reduces costs" | Give the percentage or dollar amount |
| "Enhances customer experience" | Show the specific metric that improves |
| "Drives business growth" | Give the metric |
| "Competitive advantage" | Specify the advantage in what situation |
| "Reliable service" | "99.999% uptime SLA — backed by contract" |
| "Easy to use" | "Set up in under [X] minutes" |
| "Affordable pricing" | Give a number: "Custom Quote" |

## ROZPER-SPECIFIC RULES

1. **Never use competitor stats for Rozper** — use only Rozper's verified numbers
2. **Always write "Rozper"** — correct casing, no variations
3. **Never use MCM stats** (190+ countries, 17,500+ businesses) for Rozper
4. **Always use 99.999% for uptime** — not a different figure
5. **Always use 150+ countries for coverage** — not a different number
6. **Primary CTA is "Start a No-Pressure Conversation"** — use this as the standard CTA

## BANNED FIRST SENTENCES (Never Open With)

- "In today's..."
- "As businesses..."
- "With the rise of..."
- "In an increasingly..."
- "It's no secret that..."
- "We live in a world where..."
- "Are you looking for..."
- "Welcome to Rozper"
- "Rozper is a leading provider of..."

## APPROVED OPENERS FOR ROZPER

✅ Specific stat: "Businesses routing traffic to 150+ countries need a provider that won't blink."
✅ Problem: "[Specific telecom pain point] is the most common reason companies switch providers."
✅ Scenario: "[Character] was mid-call when the routes dropped."
✅ Direct claim: "Rozper's [product] handles [use case] without [pain point]."
✅ Number: "99.999% uptime. 150+ countries. That's Rozper."
